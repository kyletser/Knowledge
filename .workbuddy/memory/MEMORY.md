## claude-blog-sync 精选规则（2026-08-17 确立）
中文译文库定位为**架构判断与工程经验精选**，不收录：
- 产品发布与功能介绍（"今天我们推出 X""现在可用"）
- 平台集成与合作动态（"X 现已支持 Claude"）
- 营销系列与个人化风格文章
- 厂商自家数据栈宣传（信息密度低、客户案例色彩重）

保留标准：讲设计原则、最佳实践、工程经验、架构判断——穿越模型与产品迭代周期。
