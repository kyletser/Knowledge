# 用技能构建智能体：为专业工作配备智能体

> 来源：Claude Blog · Anthropic
> 原文链接：[building-agents-with-skills-equipping-agents-for-specialized-work](https://claude.com/blog/building-agents-with-skills-equipping-agents-for-specialized-work)
> 发布日期：2026-01-22
> 译校：对照英文原文人工重译

---

过去一年发生了很多变化。MCP 成为智能体连接的标准，并获得了行业领导者和开发者社区的迅速采用。[Claude Code 发布](https://www.anthropic.com/news/claude-3-7-sonnet)，作为一个通用的编码智能体。我们还推出了 [Claude Agent SDK](https://www.anthropic.com/engineering/building-agents-with-the-claude-agent-sdk)，现在它开箱即用地提供生产就绪的智能体。

但当我们构建并部署这些智能体时，我们不断遇到同一个缺口：智能体具备智能与能力，却并不总是拥有有效应对真实工作的专业知识。这促使我们 [创建了智能体技能（Agent Skills）](https://www.anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills)。技能是一组组织有序的文件，将领域专业知识——工作流程、最佳实践、脚本——打包成智能体能够访问并应用的格式。它们把一个能力出众的通才，变成了一位知识渊博的专家。

在本文中，我们将解释为什么我们停止构建专用智能体、转而开始构建技能，以及这种转变如何改变了我们对扩展智能体能力的思考。

## **新范式：代码即所需**

我们曾经以为，不同领域的智能体看起来会截然不同。编码智能体、研究智能体、一个用于金融、一个用于营销——每一个似乎都需要自己的工具和脚手架。业界最初也接受了这种领域专用智能体的模式。但随着模型智能的提升和智能体能力的进步，我们最终收敛到了一种截然不同的方法。

![](images/e8f95be6ee0a-6972a852db1883d8c862151f-building-agents-with-skil.png)

我们逐渐意识到，代码与其说只是一个用例，不如说是智能体完成几乎所有数字工作的一种接口。Claude Code 是一个编码智能体，但也是一个恰好通过代码工作的通用智能体。

![](images/e28911063b9d-6972a8b8cb336e177c409445-building-agents-with-skil.png)

想想用 Claude Code 生成一份财务报告：它可以调用 API 做研究、把数据存进文件系统、用 Python 分析数据并综合出洞察。所有这一切都通过代码发生。脚手架变得像 bash 和文件系统一样简单。

但通用能力并不等于专业能力。当我们开始用 Claude Code 处理真实工作时，一个缺口浮现出来。

## **缺失的一环：领域专业知识**

如果要报税，你希望交给谁：是凭第一性原理自己推导的数学天才，还是提交过数千份纳税申报单的资深税务专业人士？大多数人会选税务专业人士。不是因为他们更聪明，而是因为他们具备恰当的专业知识。

今天的智能体就像那位数学天才：擅长对全新情境进行推理，却往往缺乏资深专业人士长期积累的专业知识。在恰当引导下，他们能做出惊人的成果。然而，他们常常遗漏重要的背景信息，难以吸收你所在组织的专业知识，也不会从重复任务中自动学习。

技能通过将领域专业知识打包成一种格式，让智能体能够逐步访问并应用，从而弥合这一鸿沟。

## **什么是智能体技能？**

智能体技能为智能体打包领域专业知识与程序性知识。

```
anthropic_brand/
├── SKILL.md
├── docs.md
├── slide-decks.md
└── apply_template.py
```

技能的简单是刻意为之的。文件是一种通用的基本单元，能与你已有的东西无缝配合。你可以用 Git 对它们做版本控制，把它们存进 Google Drive，并与团队共享。这种简单性也意味着技能创建并不局限于工程师。产品经理、分析师和领域专家已经在构建技能，将他们的工作流程规范化。

## **渐进式披露**

技能中可能包含大量信息。为了保护上下文窗口并让技能可组合，它们采用了渐进式披露：在运行时，只会向模型展示元数据（来自 YAML frontmatter 的名称和描述）。

```
---
name: Anthropic Brand Style Guidelines
description: Anthropic's official brand colors and typography…
---
```

如果 Claude 判断需要某项技能，它会读取完整的 SKILL.md 文件。如需更多细节，技能可以包含一个 references/ 目录，其中的支持文档仅在被需要时才会加载。

这种三层方法意味着，你可以给智能体配备数百项技能，而不会压垮它的上下文窗口——元数据约占用 50 个 token，完整的 SKILL.md 文件约 500 个 token，而参考文件在 2,000 个 token 以上，并且只在特别需要时才使用。

## **技能可以把脚本作为工具包含进来**

传统工具有其问题：有些指令写得不好，模型并不总是能修改或扩展它们，而且它们常常会让上下文窗口膨胀。代码则不同——它是自描述的、可修改的，并且不需要始终留在上下文中。

这里有一个真实案例：我们反复看到 Claude 编写相同的脚本，把 Anthropic 的样式应用到幻灯片上。于是我们让 Claude 把这个脚本保存为它自己的一个工具：

```
# anthropic/brand_styling/apply_template.py
import sys
from pptx import Presentation

if len(sys.argv) != 2:
    print("USAGE: apply_template.py <pptx>")
    sys.exit(1)

prs = Presentation(sys.argv[1])
for slide in prs.slides:
    ...
```

slide-decks.md 中对应的文档只是引用了这个脚本：

```
## Anthropic Slide Decks
- Intro/outro slides
  - background color: `#141413`
  - foreground color: oat
- Section slides:
  - background color: `#da7857`
  - foreground color: `#141413`

Use the `./apply_template.py` script to update a pptx file in-place.
```

## **技能生态系统**

技能生态的出现非常迅速，到目前为止，我们已经看到三种主要类型的技能正在被构建：

### **基础技能**

它们提供每个人都需要的核心能力：处理文档、电子表格、演示文稿等。它们把文档生成与操作的最佳实践编码其中。你可以探索 [我们公共仓库中的基础技能](https://github.com/anthropics/skills/tree/main/skills/public)，看看实际效果。

### **合作伙伴技能**

随着技能将智能体与专业能力的交互方式标准化，各家公司正在构建技能，让它们的服务能够被智能体访问。[K-Dense](https://github.com/K-Dense-AI/claude-scientific-skills)、[Browserbase](https://github.com/browserbase/agent-browse)、[Notion](https://www.notion.so/notiondevs/Notion-Skills-for-Claude-28da4445d27180c7af1df7d8615723d0) 以及 [许多其他公司](https://claude.com/blog/organization-skills-and-directory) 正在创建直接集成其服务的技能，在保持技能格式简洁的同时，扩展 Claude 在特定领域的能力。

### **企业技能**

组织会构建专有技能，将内部流程和领域专业知识编码其中。技能有助于捕捉具体的工作流程、合规要求以及机构知识，让智能体对企业工作变得有用。

## **我们看到的趋势**

随着技能采用的不断增长，一些模式正在浮现，预示着这个范式可能的发展方向。这些趋势塑造了我们对技能设计的思考，以及我们为支持技能开发者而构建的工具。

### **复杂度不断提升**

早期的技能只是简单的文档参考。如今我们看到的是复杂的多步骤工作流程，能够跨多个工具协调数据检索、复杂计算与格式化输出。

- **简单**："状态报告生成器"（约 100 行）——模板与格式化
- **中级**："财务模型构建器"（约 800 行）——数据检索、用 Python 做 Excel 建模
- **复杂**："RNA 测序管道"（2,500+ 行）——协调 HISAT2、StringTie、DESeq2 分析

### **技能与 MCP**

[技能与 MCP 服务器天然协同工作](https://claude.com/blog/extending-claude-capabilities-with-skills-mcp-servers)。一项竞品分析技能可能会协调网络搜索、通过 MCP 接入的内部数据库、Slack 消息记录以及 Notion 页面，从而综合出一份全面的报告。

### **非开发者采用**

技能创建正在从工程师扩展到跨学科的产品经理、分析师和领域专家。他们可以使用技能创建器（skill-creator）在 30 分钟内创建并测试自己的第一个技能，该工具会以交互方式引导他们走完整个过程。我们正致力于让技能创建变得更容易，通过改进的工具和模板，让任何人都能捕捉并分享专业知识。

## **完整的架构**

总括起来，新兴的智能体架构看起来是以下几项的组合：

1. **智能体循环（Agent loop）**：决定下一步做什么的核心推理系统
2. **智能体运行时（Agent runtime）**：执行环境（代码、文件系统）
3. **MCP 服务器**：与外部工具和数据源的连接
4. **技能库**：领域专业知识与程序性知识

![](images/f87d33e96e24-6972ab24ac6df74ad6704f37-building-agents-with-skil.png)

每一层都有明确的目的：循环负责推理，运行时负责执行，MCP 负责连接，技能负责引导。这种分离让系统易于理解，也允许各部分独立演进。

想想当你向这套架构中添加一项技能时会发生什么。[前端设计技能](https://github.com/anthropics/claude-code/tree/main/plugins/frontend-design) 会即刻改变 Claude 的前端能力。它提供关于字体排印、色彩理论与动画的专门指导，并且只在构建 Web 界面时才会激活。渐进式披露意味着它只在相关时才加载。添加新能力变得轻而易举。

## **将技能部署到新的垂直领域**

这种"配备 MCP 服务器和技能的通用智能体"新兴模式，已经帮助我们把 Claude 部署到了新的垂直领域。

### **金融服务**

在推出技能后不久，我们就增强了 [Claude 的金融服务](https://www.anthropic.com/news/claude-for-financial-services) 板块，加入让 Claude 对金融专业人士更有用的技能：

- **DCF 模型构建器**：构建折现现金流模型，包含恰当的 WACC 计算和敏感性分析
- **可比公司分析**：生成带有关键倍数和对标基准的对比表
- **盈利分析**：处理季度业绩并创建投资更新报告
- **首次覆盖**：借助财务模型构建综合研究报告
- **尽职调查**：用标准化框架构建并购分析
- **路演材料**：按照行业标准创建客户演示文稿

### **医疗保健与生命科学**

我们还增强了 [医疗保健与生命科学产品](https://www.anthropic.com/news/healthcare-life-sciences)，加入让 Claude 对研究人员、临床医生和医疗开发者更有用的技能：

- **生物信息学套件**：用于 scVI-tools 和 Nextflow 部署的技能，对管理基因组管道和单细胞 RNA 测序至关重要
- **临床试验方案生成**：加速临床研究方案的开发
- **科研选题**：帮助研究人员识别并框定有影响力的研究问题
- **FHIR 开发**：帮助开发者编写更精准的健康数据互操作性代码，更快连接医疗系统并减少错误
- **事前授权审查**：通过交叉比对承保要求、临床指南和患者记录，减轻行政负担，加快患者获得所需护理的速度

## **智能体技能标准化**

为了实现这一愿景，我们正在将 [智能体技能（Agent Skills）](https://agentskills.io) 作为开放标准发布。与 MCP 一样，我们相信技能应当可以在不同的工具与平台之间移植。无论你使用的是 Claude 还是其他 AI 平台，同一项技能都应当能用。我们一直在与生态成员合作推进这一标准，也很高兴看到它获得了早期的采用。

当有人第一次开始使用 AI 智能体时，它应该已经知道你和你的团队所看重的东西，因为技能捕捉并传递了这些专业知识。随着这个生态的成长，社区中其他人构建的技能可以让你的智能体更有用、更可靠、更强大——无论他们使用哪个 AI 平台。

## **开始使用**

我们正在就通用智能体的架构达成共识，而技能为交付和分享新能力提供了一种范式。真正的价值来自我们一起构建的集体知识库：捕捉专业知识、在团队间传递它，并让每一个智能体都比上一个更有能力。
