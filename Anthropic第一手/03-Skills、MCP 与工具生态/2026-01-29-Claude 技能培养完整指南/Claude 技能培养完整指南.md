# Claude 技能培养完整指南

> 来源：Claude Blog · Anthropic

---

技能让你可以一次性把工作流程教给 Claude，并让它始终如一地应用。本指南涵盖如何构建、测试并分发技能——无论是独立的工作流程，还是由 MCP 增强的集成。

自从 [去年十月推出技能](https://claude.com/blog/skills) 以来，我们看到众多开发者表现出浓厚兴趣：他们希望 Claude 始终遵循特定的工作流程、高级用户想要自动化文档创建或研究流程这类可重复的任务、团队希望标准化 Claude 在整个组织中的运作方式，而 MCP 连接器构建者则希望将自己的集成与可靠的工作流程配对。

共同的线索是：人们想要更详尽的指导，来构建有效的技能——无论是独立工作流程，还是由 MCP 增强的集成——从规划与结构，到测试与分发。

我们整理出这份指南来填补这一空白。它涵盖了从技术要求和技能结构，到测试方法以及常见排障模式的一切内容。无论你是在构建与 Claude 内置能力配合的独力技能，还是在增强某个 MCP 集成，你都会发现相关的指导——我们还为需要的人准备了专门讲解 MCP + 技能的章节。

**你将学到：**

- 技能结构的技术要求与最佳实践
- 独力技能与 MCP 增强工作流程的模式
- 在不同用例中都已被验证有效的模式
- 如何测试、迭代并分发你的技能

如果你已经确定了最想自动化的 2–3 个工作流程，那么使用技能创建器（skill-creator）构建并测试出第一个可用的技能，预计大约需要 15–30 分钟。

**适用对象：**

- 希望 Claude 始终遵循特定工作流程的开发者
- 想要把工作流程知识加入集成的 MCP 连接器构建者
- 需要自动化可重复任务的高级用户
- 希望标准化 Claude 在整个组织中运作方式的团队
