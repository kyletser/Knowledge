# Claude Code 现在支持工件

> 发布日期：2026-06-18 · [原文链接](https://claude.com/blog/artifacts-in-claude-code) · 机器翻译，仅供学习。

从今天开始，Claude Code 可以将工作进度捕获为工件，从而将 Claude Code 的工作转化为实时、可共享的可视化页面（包括 PR 演练、系统解释器、仪表板和发布清单），并在会话进行时进行自我更新。

Claude Code 会话的范围可以从调查事件到重构服务再到分析数月的数据。工件将工作转换为任何人都可以打开和探索的网页，例如拉取请求演练、可以过滤和排序的仪表板，甚至是在工作完成时自动填写的发布清单。  工件使共享工作的协作变得更加容易，因此团队可以花更多的时间进行构建，而减少沟通状态更新的时间。

[视频：使用 Claude Code 中的 Artifacts 以不同的方式查看您的项目](https://www.youtube.com/embed/m7TJqx8CYG8)

## **基于您的会话上下文**

Claude Code 使用会话的完整上下文构建工件，包括代码库、连接器和对话本身。单个事件页面可以将代码中失败的测试及其背后的功能、连接的监视工具中的错误峰值以及您刚刚运行的会话中的根本原因推理汇集在一起​​。有了工件，您无需连接数据源或建立基础设施。您请求一个页面，Claude Code 会根据已有的内容构建它。

## **就地更新的实时页面**

当 Claude Code 更新工件时，打开的页面会就地刷新，团队成员会在更新发布后立即看到更新。每次发布都是同一链接上的新版本，具有版本历史记录，因此您可以随时恢复，并且图库可让您浏览和管理您制作的所有工件。

根据我们的内部测试，我们最常见的用例之一是调试。这些通常看起来像这样：工程师在站立之前开始事件调查。 Claude Code 处理日志并发布工件：时间线、可疑提交和错误率图表。她与她的团队分享了页面标题中的链接。截至站立会议开始时，Claude 已随着调查的进展重新发布了两次，并纳入了最新信息。有了工件，团队成员和利益相关者不必“引导我们了解智能体的发现”，因为他们都在相同的上下文中查看相同的视图。

## **您的组织私有**

默认情况下，每个工件对其作者都是私有的。准备好后，直接从页面与您的队友和您的组织共享。工件只能由组织中经过身份验证的成员查看，并且不能公开。管理员通过组织级别切换和基于角色的范围来管理访问权限，设置保留策略，并通过合规性 API 获得组织范围内的可见性。

## **开始使用**

向您的会议请求一个工件 - 或者只是请求一些视觉效果，h*以下是按角色划分的一些想法：*

- **合法/开源**：直接从存储库对每个依赖项进行许可证审核，标记 Copyleft。 *“构建一个工件，列出每个第三方依赖项及其许可证，标记任何 Copyleft。”*
- **隐私**：通过代码收集、存储和记录个人数据的数据流图。 *“追踪我们在代码库中接触个人数据的位置，将其转化为用于隐私审查的工件。”*
- **安全性**：链接到确切行的调查结果，因此修复是明确的。 *“根据本次审查的授权结果构建一个工件，每个结果都与代码相关联。”*
- **FinOps/平台金融**：从基础设施即代码映射的云资源和成本驱动因素。 *“将我们的云资源从 Terraform 映射到工件中，按服务分组，并具有巨大的成本驱动因素。”*
- **软件工程师**：PR 或 bug 演练审核者实际上可以遵循，从 diff 及其周围的代码中提取。 “制作一个工件来遍历这个 PR——差异、推理以及我测试的内容。”
- **设计师和前端工程师**：屏幕的多个用户体验方向，每个方向都由您的真实组件构建，因此您选择的那个是可交付的。 “给我一个包含此注册表单 5 个 UX 变体的工件，它是从我们的组件库构建的。”
- **工程师和建筑师**：服务如何实际组合在一起的地图，从真实的导入图而不是白板上绘制。 “从代码中映射支付服务如何组合成一个工件。”
- **SRE 和待命人员**：事件页面会随着您的调查而增长并成为事后分析。 “把这个事件变成一个工件——时间线、可疑的提交、我们监控中的错误峰值——并在我处理它时重新发布。”
- **工程经理**：实际发布内容的页面，由合并的 PR 构建。 “根据本周我的团队从 PR 中合并的内容构建一个工件，并按项目分组。”

Claude Code 构建页面并为您提供链接。在浏览器或桌面应用程序中打开它，从标题共享它 - 更新会自动发布到同一 URL。

## **可用性**

Artifacts 的测试版可从 Claude Code CLI 和桌面应用程序向 Claude 团队和企业组织提供，页面可在任何浏览器中查看。
