# Claude 技能培养完整指南

> 发布日期：2026-01-29 · [原文链接](https://claude.com/blog/complete-guide-to-building-skills-for-claude) · 机器翻译，仅供学习。

自从 [十月推出技能](https://claude.com/blog/skills)，我们看到了开发人员的强烈兴趣，他们希望 Claude 始终遵循特定的工作流程，高级用户自动化可重复的任务，例如文档创建或研究流程，希望标准化 Claude 在整个组织中的运作方式的团队，以及 MCP 连接器构建器将其集成与可靠的工作流程配对。

共同点是：人们希望获得更详细的指导来构建有效的技能——无论是独立工作流程还是 MCP 增强的集成——从规划和结构到测试和分发。

我们整理了本指南来填补这一空白。它涵盖了从技术要求和技能结构到测试方法和常见故障排除模式的所有内容。无论您是构建与 Claude 的内置功能配合使用的独立技能，还是增强 MCP 集成，您都会发现相关的指南 - 为那些需要它的人提供了关于 MCP + 技能的专门部分。

**你将学到什么：**

- 技能结构的技术要求和最佳实践
- 独立技能和 MCP 增强工作流程的模式
- 适用于不同用例的模式
- 如何测试、迭代和分配您的技能

如果您知道想要自动化的前 2-3 个工作流程，则预计需要大约 15-30 分钟的时间来使用技能创建器构建和测试您的第一个工作技能。

**这是给谁的：**

- 希望 Claude 始终遵循特定工作流程的开发人员
- MCP 连接器构建者将工作流程知识添加到其集成中
- 高级用户自动执行可重复的任务
- 希望标准化 Claude 在整个组织中的工作方式的团队
