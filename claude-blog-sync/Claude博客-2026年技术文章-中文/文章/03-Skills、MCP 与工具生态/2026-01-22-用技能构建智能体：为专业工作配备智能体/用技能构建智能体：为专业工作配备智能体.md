# 用技能构建智能体：为专业工作配备智能体

> 发布日期：2026-01-22 · [原文链接](https://claude.com/blog/building-agents-with-skills-equipping-agents-for-specialized-work) · 机器翻译，仅供学习。

过去一年发生了很多变化。 MCP 成为智能体连接的标准，并得到行业领导者和开发人员社区的迅速采用。 [Claude Code 推出](https://www.anthropic.com/news/claude-3-7-sonnet) 作为通用编码智能体。我们推出了 [Claude Agent SDK](https://www.anthropic.com/engineering/building-agents-with-the-claude-agent-sdk)，现在提供了开箱即用的生产就绪型智能体。

但当我们构建和部署这些智能体时，我们不断遇到同样的差距：智能体具有智能和能力，但并不总是具有有效解决实际工作的专业知识。这导致我们 [创建智能体技能](https://www.anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills)。技能是有组织的文件集合，以智能体可以访问和应用的格式打包领域专业知识（工作流程、最佳实践、脚本）。他们将一个有能力的通才变成了一个知识渊博的专家。

在这篇文章中，我们将解释为什么我们停止构建专门的智能体并开始构建技能，以及这种转变如何改变我们对扩展智能体功能的看法。

## **新范式：代码就是你所需要的**

我们曾经认为智能体在不同的域中看起来会非常不同。编码智能体，研究智能体，一个用于财务，一个用于营销 - 每个似乎都需要自己的工具和脚手架。业界最初接受了特定领域智能体的模型。但随着模型智能水平的提高和智能体能力的进步，我们集中在一种不同的方法上。

![](images/e8f95be6ee0a-6972a852db1883d8c862151f-building-agents-with-skil.png)

我们开始不再将代码视为一个用例，而是将其视为智能体几乎可以完成任何数字工作的接口。 Claude Code 是一个编码智能体，但也是一个恰好通过代码工作的通用智能体。

![](images/e28911063b9d-6972a8b8cb336e177c409445-building-agents-with-skil.png)

考虑使用 Claude Code 生成财务报告。它可以调用 API 进行研究、将数据存储在文件系统中、使用 Python 进行分析并综合见解。所有这些都是通过代码发生的。脚手架变得像 bash 和文件系统一样简单。

但一般能力并不等同于专业知识。当我们开始使用 Claude Code 进行实际工作时，出现了一个差距。

## **缺失的部分：领域专业知识**

您希望谁来报税：是根据基本原理计算出来的数学天才，还是提交了数千份申报表的经验丰富的税务专业人士？大多数人会选择税务专业人士。不是因为他们更聪明，而是因为他们拥有正确的专业知识。

今天的智能体就像那个数学天才：擅长通过新奇的情况进行推理，但往往缺乏经验丰富的专业人士所积累的专业知识。在适当的指导下，他们可以做出惊人的事情。然而，他们通常会错过重要的背景，无法轻松吸收组织的专业知识，并且不会自动从重复的任务中学习。

技能通过以智能体可以逐步访问和应用的格式打包领域专业知识来弥补这一差距。

## **智能体技能是什么？**

智能体的技能包领域专业知识和程序知识。

```
anthropic_brand/
├── SKILL.md
├── docs.md
├── slide-decks.md
└── apply_template.py
```

技能的简单性是经过深思熟虑的。文件是一种通用原语，可以与您已有的文件一起使用。您可以使用 Git 对它们进行版本控制，将它们存储在 Google Drive 中，并与您的团队共享。这种简单性也意味着技能创造不仅限于工程师。产品经理、分析师和领域专家已经在培养技能来规范他们的工作流程。

## **渐进式披露**

技能可以包含广泛的信息。为了保护上下文窗口并使技能可组合，他们使用渐进式公开：在运行时，仅向模型显示元数据（YAML frontmatter 中的名称和描述）。

```
---
name: Anthropic Brand Style Guidelines
description: Anthropic's official brand colors and typography…
---
```

如果 Claude 确定需要某项技能，它将读取完整的 SKILL.md 文件。对于更多详细信息，技能可以包括一个引用/目录，其中包含仅按需加载的支持文档。

这种三层方法意味着您可以为智能体配备数百种技能，而不会压垮其上下文窗口 - 元数据使用约 50 个令牌，完整的 SKILL.md 文件约 500 个令牌，参考文件使用 2,000 多个令牌，并且仅在特别需要时使用。

## **技能可以包括脚本作为工具**

传统工具存在问题：有些指令编写得不好，模型不能总是修改或扩展它们，而且它们经常使上下文窗口膨胀。另一方面，代码是自记录的、可修改的，并且不需要始终处于上下文中。

这是一个真实的示例：我们不断看到 Claude 编写相同的脚本来将 Anthropic 样式应用于幻灯片。所以我们要求Claude将其保存为自己的工具：

```
# anthropic/brand_styling/apply_template.py
import sys
from pptx import Presentation

if len(sys.argv) != 2:
    print("USAGE: apply_template.py <pptx>")
    sys.exit(1)

prs = Presentation(sys.argv[1])
for slide in prs.slides:
    ...
```

Slide-演示文稿.md 中的相应文档仅引用了此脚本：

```
## Anthropic Slide Decks
- Intro/outro slides
  - background color: `#141413`
  - foreground color: oat
- Section slides:
  - background color: `#da7857`
  - foreground color: `#141413`

Use the `./apply_template.py` script to update a pptx file in-place.
```

## **技能生态系统**

技能生态系统迅速兴起，到目前为止，我们已经看到了三种主要类型的技能正在建立：

### **基础技能**

它们提供了每个人都需要的核心功能：处理文档、电子表格、演示文稿等。它们编码了文档生成和操作的最佳实践。您可以通过探索来了解实践中的情况 [我们公共存储库中的基本技能](https://github.com/anthropics/skills/tree/main/skills/public).

### **合作伙伴技能**

随着技能标准化智能体与专业能力交互的方式，公司正在构建技能以使其服务智能体易于访问。 [K-密集](https://github.com/K-Dense-AI/claude-scientific-skills), [浏览器库](https://github.com/browserbase/agent-browse), [概念](https://www.notion.so/notiondevs/Notion-Skills-for-Claude-28da4445d27180c7af1df7d8615723d0), 和 [还有很多其他人](https://claude.com/blog/organization-skills-and-directory) 正在创建直接集成其服务的技能，扩展 Claude 在特定领域的功能，同时保持技能格式的简单性。

### **企业技能**

组织建立编码其内部流程和领域专业知识的专有技能。技能有助于捕获特定的工作流程、合规性要求和机构知识，使智能体对企业工作有用。

## **我们看到的趋势**

随着技能采用的增长，出现了几种模式，这些模式指出了这种范式可能的发展方向。这些趋势塑造了我们对技能设计以及我们为支持技能开发人员而构建的工具的看法。

### **复杂性增加**

早期的技能是简单的文档参考。现在，我们看到复杂的多步骤工作流程，可以跨多个工具协调数据检索、复杂计算和格式化输出。

- **简单**：“状态报告编写器”（约 100 行）- 模板和格式
- **中级**：“Financial模型builder”（约 800 行）- 数据检索、使用 Python 进行 Excel 建模
- **综合体**：“RNA 测序管道”（2,500 多行）- 协调 HISAT2、StringTie、DESeq2 分析

### **技能与 MCP**

[技能与MCP服务器协同工作](https://claude.com/blog/extending-claude-capabilities-with-skills-mcp-servers) 自然地。竞争性分析技能可能会协调网络搜索、通过 MCP 的内部数据库、Slack 消息历史记录和概念页面来合成综合报告。

### **非开发人员采用**

技能创造正在从工程师扩展到跨学科的产品经理、分析师和领域专家。他们可以使用技能创建工具在 30 分钟内创建并测试他们的第一个技能，该工具以交互方式指导他们完成整个过程。我们正在努力通过改进的工具和模板让技能创建变得更加容易，让任何人都可以捕获和分享专业知识。

## **完整的架构**

总而言之，新兴的智能体架构看起来像是以下各项的组合：

1. **智能体循环**：决定下一步做什么的核心推理系统
2. **智能体运行时**：执行环境（代码、文件系统）
3. **MCP 服务器**：与外部工具和数据源的连接
4. **技能库**：领域专业知识和程序知识

![](images/f87d33e96e24-6972ab24ac6df74ad6704f37-building-agents-with-skil.png)

每一层都有明确的目的：循环原因、运行时执行、MCP 连接和技能指南。这种分离使得系统易于理解，并允许每个部分独立发展。

考虑一下当您向此架构添加一项技能时会发生什么。的 [前端设计技巧](https://github.com/anthropics/claude-code/tree/main/plugins/frontend-design) 立即改变 Claude 的前端能力。它提供有关版式、色彩理论和动画的专门指导，仅在构建 Web 界面时激活。渐进式披露意味着它仅在相关时加载。添加新功能非常简单。

## **将技能部署到新的垂直领域**

这种配备 MCP 服务器和技能的通用智能体的新兴模式已经帮助我们将 Claude 部署到新的垂直领域。

### **金融服务**

刚推出技能后，我们就增强了 [Claude 金融服务](https://www.anthropic.com/news/claude-for-financial-services) 具有使 Claude 对金融专业人士更有用的技能的部门：

- **DCF模型生成器**：通过适当的 WACC 计算和敏感性分析构建贴现现金流模型
- **可比公司分析**：生成具有相关倍数和基准的比较表
- **盈利分析**：处理季度业绩并创建投资更新报告
- **启动覆盖范围**：利用财务构建综合研究报告模型
- **尽职调查**：利用标准化框架构建并购分析
- **沥青材料**：按照行业标准创建客户演示文稿

### **医疗保健与生命科学**

我们还增强了我们的 [医疗保健和生命科学产品](https://www.anthropic.com/news/healthcare-life-sciences) 拥有使 Claude 对研究人员、临床医生和医疗保健开发人员更有用的技能：

- **生物信息学包**：scVI 工具和 Nextflow 部署技能，对于管理基因组管道和单细胞 RNA 测序至关重要
- **临床试验方案生成**：加速临床研究方案的开发
- **科学选题**：帮助研究人员识别和框架有影响力的研究问题
- **FHIR开发**：帮助开发人员编写更准确的健康数据互操作性代码，更快地连接医疗保健系统并减少错误
- **事前授权审查**：通过交叉引用承保要求、临床指南和患者记录，减轻管理负担并加快患者获得所需护理的速度

## **标准化智能体技能**

为了实现这一愿景，我们正在发布 [智能体技能](https://agentskills.io) 作为一个开放标准。与 MCP 一样，我们相信技能应该可以跨工具和平台移植。无论您使用 Claude 还是其他 AI 平台，都应该使用相同的技能。我们一直在与生态系统成员就该标准进行合作，我们很高兴看到该标准得到早期采用。

当有人第一次开始使用 AI智能体时，它应该已经知道您和您的团队关心什么，因为技能捕获并转移了该专业知识。随着这个生态系统的发展，社区中其他人构建的技能可以使您的智能体更加有用、可靠和强大 - 无论他们使用哪个 AI 平台。

## **开始使用**

我们正在融合通用智能体的架构，而技能为交付和共享新功能提供了范例。真正的价值来自于我们共同构建的集体知识库：获取专业知识，在团队之间进行转移，并使每个智能体都比上一个更有能力。
