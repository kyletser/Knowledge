# 在桌面上重新设计 Claude Code 以实现并行智能体

> 发布日期：2026-04-14 · [原文链接](https://claude.com/blog/claude-code-desktop-redesign) · 机器翻译，仅供学习。

它包括一个用于管理多个会话的新侧边栏、一个用于安排工作空间的拖放布局、一个集成终端和文件编辑器，以及性能和生活质量的改进。

[视频：新的 Claude Code 桌面应用程序，针对并行智能体重新设计](https://www.youtube.com/embed/rWaQSQEm_aY)

## 全新桌面体验

对于许多开发者来说，智能体式作品的形态已经发生了变化。您不会输入提示词并等待。您在一个存储库中开始重构，在另一个存储库中修复错误，在第三个存储库中进行测试编写，在结果出现时检查每个存储库，在出现偏差时进行指导，并在发布之前检查差异。

新应用程序专为智能体式编码现在的实际感受而构建：许多事情都在飞行中，而您则坐在编排者的座位上。

## 并行运行会话

新的侧边栏将每个活动的和最近的会话放在一个位置。在多个存储库中开始工作，并在结果到达时在它们之间移动。

您可以按状态、项目或环境进行过滤，或按项目对侧边栏进行分组，以更快地查找和恢复会话。当会话的 PR 合并或关闭时，它会自行存档，以便侧边栏始终专注于实时内容。

当您需要在任务中提出问题时，可以打开侧聊（⌘ + ; 或 Ctrl + ;）来分支对话。边聊从主线程中提取上下文，但不要将任何内容添加回线程，以避免误导您的任务。

## 无需离开应用程序即可查看并发货

重新设计将更多常用工具引入应用程序，因此您可以查看、调整和发布 Claude 的作品，而无需跳转到编辑器：

- **综合终端**：在会话期间运行测试或构建。
- **应用内文件编辑器**：打开文件，直接进行定点编辑，然后保存更改。
- **更快的差异查看器**：针对大型变更集的性能进行了重建。
- **扩展预览**：除了在预览窗格中运行本地应用程序服务器之外，还可以在应用程序内打开 HTML 文件或 PDF。

每个窗格都是拖放式的。根据您的工作方式安排终端、预览、差异查看器和聊天。

## 适合您的堆栈

桌面应用程序现在与 CLI 插件具有同等地位。如果您的组织集中管理 Claude Code 插件，或者您已在本地安装了自己的插件，则它们在桌面应用程序中的工作方式与在终端中的工作方式完全相同。

您仍然可以在本地或云中运行会话。 SSH 支持现在已扩展到 Mac 和 Linux，因此您可以从任一平台将会话指向远程计算机。

## 根据您的工作方式进行定制

三种视图模式 - 详细、正常和摘要 - 让您可以将界面从完全透明转为仅显示结果的 Claude 工具调用。新的键盘快捷键涵盖会话切换、生成和导航；按 `⌘ + /` （或 `Ctrl + /`）查看完整列表。新的使用情况按钮可以让您的上下文窗口和会话使用情况一目了然。

在后台，该应用程序已针对可靠性和速度进行了重建，现在可以在 Claude 生成响应时流式传输响应。

## 开始使用

重新设计的桌面应用程序现在可供 Pro、Max、Team 和 Enterprise 计划的所有 Claude Code 用户通过 Claude API 使用。

[下载应用程序](https://claude.com/download)，或者更新并重新启动（如果您已经有）。探索 [文档](https://docs.claude.com/claude-code) 了解更多。
