# 与合规部门 API 一起审核 Claude Platform 活动

> 发布日期：2026-03-30 · [原文链接](https://claude.com/blog/claude-platform-compliance-api) · 机器翻译，仅供学习。

## 与合规部门 API 一起审核 Claude Platform 活动

合规性 API 现已在 Claude Platform 上提供，使管理员能够以编程方式访问整个组织的审核日志。安全和合规团队可以跟踪用户活动、监控配置更改并将 Claude 使用数据集成到其现有的合规基础设施中。

## 为您的组织审核日志记录

金融服务、医疗保健、法律等受监管行业的组织需要详细记录谁访问了什么、何时访问以及发生了什么变化。如果无法以编程方式访问这些数据，合规团队就需要依赖手动导出和定期审核，而这无法扩展。

合规性 API 提供了一个活动源，用于记录整个组织中与安全相关的事件。管理员可以获取按时间范围、特定用户或 API 键过滤的活动日志。

API 当前跟踪两类活动：

- **管理和系统活动：** 修改资源的访问或配置的操作，例如向工作区添加成员、创建 API 密钥、更新帐户设置或修改实体访问。
- **资源活动：** 创建或修改资源数据的用户驱动操作，例如创建文件、下载文件或删除技能。这些涵盖可能影响数据或允许资源访问敏感信息的操作，不包括与模型的直接交互。

这些事件共同涵盖了用户登录和注销事件、帐户设置更新、工作区更改和其他组织审核事件。 API 不记录推理活动，例如用户与模型或模型活动的交互。

## 开始使用

请联系您的客户团队，为您的组织启用合规性 API。启用后，创建管理 API 密钥并使用它来查询活动源端点。请注意，一旦启用 API，日志记录就会开始 — 该点之前的历史活动不可用。

已使用 Claude Enterprise 合规性 API 的组织可以将其 Claude API 组织添加到同一父组织，并从单个源过滤这两个组织的活动。

阅读有关的文档 [Anthropic 信任中心](https://trust.anthropic.com/resources?s=tob70gqyan60x3dwb7nkap&name=anthropic-compliance-api) 了解更多。
